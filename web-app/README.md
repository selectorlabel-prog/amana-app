# معرض تصاميم أمانة (مرجع فقط)

تطبيق ويب ثابت يجمع 49 شاشة مولدة من Google Stitch في مكان واحد:

- 16 شاشة للعميل
- 15 شاشة لمقدم الخدمة
- 16 شاشة للإدارة
- بوابتان للدخول

هذا المجلد **ليس تطبيق أمانة الوظيفي**، ولا يحتوي Backend أو مصادقة أو
بيانات مشتركة، ولا ينتج APK. الغرض منه مرجع بصري أثناء تحويل التصميم تدريجيًا
إلى Flutter widgets. لا يحتاج المعرض إلى تثبيت حزم أو عملية بناء.

## التشغيل

من جذر المشروع شغّل:

```powershell
py -m http.server 8080 --directory web-app
```

ثم افتح:

```text
http://localhost:8080
```

يمكن أيضًا فتح `index.html` مباشرة، لكن الخادم المحلي أكثر توافقًا مع معاينات `iframe`.
على الأنظمة التي يتوفر فيها الأمر `python` بدل مشغّل Windows، استخدم
`python -m http.server 8080 --directory web-app`.

## الهيكل

- `index.html`: فهرس قابل للبحث والتصفية ومعاينة الشاشات.
- `screens/customer`: تصاميم العميل.
- `screens/provider`: تصاميم مقدم الخدمة.
- `screens/admin`: تصاميم الإدارة.
- `screens/gateway`: بوابات الدخول.
- `design-notes`: ملفات نظام التصميم الأصلية المرافقة.

ملفات الشاشات منسوخة دون تعديل للحفاظ على RTL والعربية والتصميم الأصلي. قد تحتاج بعض الخطوط والصور ومكتبات Tailwind المستخدمة في ملفات Stitch إلى اتصال بالإنترنت.
